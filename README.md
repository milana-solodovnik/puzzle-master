# PuzzleMaster — интерактивная развивающая игра-пазл

Веб-приложение для детей: собираем пазлы из ярких картинок, зарабатываем достижения
и открываем новые изображения. Курсовой проект (Python, Flask).

![Пример пазла](static/puzzle3.jpg)

## Возможности

- Регистрация и авторизация пользователей (пароли хранятся в виде хешей)
- Три уровня сложности: 2×2, 3×3, 4×4
- Отслеживание достижений и разблокировка новых картинок
- Сохранение лучшего времени прохождения для каждого уровня
- Перетаскивание деталей мышью, проверка сборки, таймер

## Стек

- **Python 3** — серверная логика
- **Flask** — маршруты, шаблоны (Jinja2), сессии
- **SQLAlchemy + SQLite** — модели User / Achievement, хранение результатов
- **HTML/CSS + JavaScript** — игровое поле, drag-and-drop
- **Tkinter + Pillow** — ранняя десктопная версия игры (`puzzle_game.py`)

## Запуск

```bash
pip install -r requirements.txt
python run.py
```

Приложение откроется на http://localhost:5001.
База SQLite создаётся автоматически при первом запуске (папка `instance/`).

## Структура проекта

```
main.py               — приложение Flask: маршруты, игровая логика
models.py             — модели SQLAlchemy (User, Achievement)
run.py / app.py       — точка входа
achievement_manager.py, user_manager.py, data_handler.py — модули бизнес-логики
puzzle_game.py        — десктопная версия (Tkinter)
static/, templates/   — картинки пазлов, стили, HTML-шаблоны
```
